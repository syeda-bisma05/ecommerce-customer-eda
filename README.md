# E-commerce Customer Behavior Analysis

Exploratory data analysis of 500 online store customers (Kaggle Ecommerce Customers dataset): how session time, app time, website time and membership length relate to yearly spending.

## Key Findings
- Length of Membership is the strongest driver of spending (correlation 0.81).
- Time on App has a moderate effect (0.50), while Time on Website has almost none (about 0.00).
- Top 10% spenders have longer membership (4.89 vs 3.38 years) and more app time (13.10 vs 11.94 minutes).
